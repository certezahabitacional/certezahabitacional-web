# Certeza Habitacional Web

Primera versión del sitio corporativo de Certeza Habitacional.

## Desarrollo local

```bash
npm install
npm run dev
```

Abrir http://localhost:3000

## Publicación en Vercel

1. Subir todos los archivos a la rama `main` del repositorio.
2. Importar el repositorio en Vercel.
3. Vercel debe detectar automáticamente **Next.js**.
4. Desplegar.
5. Agregar `certezahabitacional.com` y `www.certezahabitacional.com` en Settings > Domains.

## Antes de publicar

Revisar y actualizar:
- correo de contacto;
- cobertura geográfica;
- textos legales;
- teléfono/WhatsApp;
- formulario de contacto (actualmente abre el cliente de correo mediante `mailto:`).
