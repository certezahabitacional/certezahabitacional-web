INSTALACION
1. Deten npm run dev.
2. Extrae CERTEZA_SPRINT_11_CORREGIDO dentro de la raiz del proyecto.
3. Desde PowerShell, en la raiz del proyecto, ejecuta:

powershell -ExecutionPolicy Bypass -File .\CERTEZA_SPRINT_11_CORREGIDO\INSTALAR_SPRINT_11_CORREGIDO.ps1

4. Espera el mensaje SPRINT_11_CORREGIDO_INSTALADO.
5. Ejecuta npm run dev.
6. Abre http://localhost:3000/panel/inspecciones/nueva

IMPORTANTE
- El instalador crea un respaldo antes de reemplazar archivos.
- No modifica prisma/schema.prisma.
- No requiere una nueva migracion.
- Los archivos internos usan extension .txt para que Next.js no los compile dentro de la carpeta del instalador.
