INSTALACION
1. Haz una copia de seguridad del proyecto.
2. Copia todas las carpetas de este ZIP dentro de la raíz de:
   C:\Users\GILSAR\GitHub\certezahabitacional-web
3. Cuando Windows pregunte, selecciona "Reemplazar los archivos en el destino".
4. No borres ni reemplaces .env.local.
5. En PowerShell, dentro del proyecto, ejecuta:
   npm run build
6. Si termina correctamente, realiza Commit y Push desde GitHub Desktop.
